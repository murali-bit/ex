Put PDF.js here:

  pdf.min.js
  pdf.worker.min.js

Get them from (version 3.11.174 tested):
  https://cdnjs.cloudflare.com/ajax/libs/pdf.js/3.11.174/pdf.min.js
  https://cdnjs.cloudflare.com/ajax/libs/pdf.js/3.11.174/pdf.worker.min.js

Chrome MV3 CSP blocks remote <script src>, so these must be local files.
